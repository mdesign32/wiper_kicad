# Wiper

Печатная плата контроллера (ATmega, реле), KiCad 9.0.7.

| Файл | Назначение |
|---|---|
| `wiper.kicad_pro` | проект |
| `wiper.kicad_sch` | схема |
| `wiper.kicad_pcb` | печатная плата (2 слоя, 90 × 67,5 мм, 1,6 мм) |

Все символы и посадочные места взяты из стандартных библиотек KiCad 9.

Гербер-файлы изготовленных версий прикладываются к релизам на GitHub.
